# Design notes

Visual lock: the Attio-inspired landing screenshot (lilac bloom, screenshot product card, Inter). Do not restyle into another product’s palette or type.

**Motion:** follow [`design/animations-rules.md`](./animations-rules.md). Version A lock (Pattern B/C, lilac, screenshot card) plus reversible Pattern A / A2 split-text on landing gray headers. Opacity + transform only. Hover 150–200ms ease-out. `prefers-reduced-motion` in CSS and JS.
